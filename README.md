# Gestor de inventario

## Objetivo
Programa de consola desarrollado en Python para administrar el inventario de una tienda mediante listas paralelas.

## Requisitos
- Python 3 instalado.
- Terminal o editor de código.
- No requiere librerías externas.

## Instrucciones de uso
1. Ejecutar el archivo Python desde la terminal:
   ```bash
   python inventario.py
   ```
2. Seleccionar una opción del menú ingresando un número del 1 al 8.
3. Seguir las instrucciones para registrar, consultar, modificar o eliminar productos.
4. Seleccionar la opción 8 para salir.

## Funciones implementadas
- Registrar productos y cantidades, evitando duplicados.
- Mostrar y buscar productos.
- Modificar cantidades disponibles.
- Eliminar productos.
- Contar productos registrados.
- Identificar el producto con mayor cantidad.
- Validar entradas y opciones del menú.
